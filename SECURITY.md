# Security

Chronos is a defensive tool for authorized analysis. We take the security of
the project itself seriously.

## Reporting a vulnerability

**Do not open a public issue** for security-related problems. Report them
privately using the GitHub Security Advisories flow:

1. Go to the repository → *Security* tab → *Report a vulnerability*.
2. Describe the issue, the affected version, and a minimal reproducer.
3. You will receive an acknowledgment within 5 business days.

Please only use this channel for genuine security issues in the Chronos
codebase (e.g. a flaw in the tracer, sinkhole, or storage layers). Misuse of
the tool to instrument software you are not authorized to analyze is out of
scope.

## Expectations

- We will acknowledge reports promptly.
- We will keep you informed about the fix and a coordinated disclosure date.
- Non-sensitive bugs and feature requests go through the regular issue
  tracker.
